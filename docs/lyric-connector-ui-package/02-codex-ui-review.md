# Lyric Connector UI 重构后设计审查与修复

请对刚完成的 Lyric Connector UI 重构进行一次设计与工程审查，并直接修复发现的问题。参考 `01-codex-ui-refactor.md` 和 `lyric-connector-ui-design.png`，但保留原有双 Tab 信息架构。

重点检查：

1. 是否出现过度 Card 化、无意义容器嵌套、大面积空白或多层滚动条。
2. 分区标题、控件标签、输入框和按钮是否形成统一对齐基线。
3. 是否还有适合合并为单行的设置项，以及窄窗口下是否能合理换行。
4. 是否在同一区域出现多个同等视觉权重的主按钮。
5. 整体是否比重构前更紧凑，同时仍然清晰易读。
6. 连接、播放、搜索、导入、歌词选用、悬浮显示、设置持久化是否完整工作。
7. 搜索未开始/加载中/成功/无结果/失败以及连接状态是否准确。
8. 是否引入不必要的依赖、复杂组件、重复业务代码或过多重绘。
9. Windows DPI 100%、125%、150% 下是否存在截断、重叠或横向滚动。
10. 是否错误地把两个原有 Tab 改成固定左右双栏；如果有，请恢复双 Tab。

请按照“发现的问题 → 修改方式 → 实际修改文件 → 验证结果”输出简要报告，并直接修复。不要仅给建议。

**不要继续添加 Card、阴影、渐变、装饰性图标或仅用于包装的组件，也不要重复设计已经符合要求的部分。**
