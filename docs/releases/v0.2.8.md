Lyric Connector 0.2.8 for Windows x64.

## 本次更新

- 优化 Spotify 等播放器的歌曲面板：将歌曲信息、播放控制和蓝牙状态分区排列，并把当前时间与总时长移到进度条两端。
- 新增上一首、播放 / 暂停、下一首控制，并改进按钮状态和进度条悬停显示。
- 修复切换播放器时连续元数据通知反复推迟歌曲快照的问题，让新播放器信息能够及时同步。

## 下载文件

- `LyricConnector-Setup-0.2.8-x64.exe`：单用户安装程序。
- `LyricConnector-0.2.8-win-x64.zip`：完整便携运行目录，解压后启动主程序。
- `LyricConnector.exe`：主程序；单独运行时仍需要 ZIP 中的配置文件和资源目录。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 运行要求

- Windows 10 / 11 x64，.NET Framework 4.8 或更高版本。
- 可用的蓝牙 LE 适配器，以及已在 Windows 中配对的 iPhone。
- 程序未签名，尚未完成干净 Windows 环境安装验收。
