Lyric Connector 0.2.6 for Windows x64.

## 本次更新

- 首次成功连接手机前默认展开设备管理；连接成功后，之后启动时默认收起，可随时手动展开。
- 连接帮助默认收起；连接意外失败时自动显示，手动断开时不显示。

## 下载文件

- `LyricConnector-Setup-0.2.6-x64.exe`：单用户安装程序。
- `LyricConnector-0.2.6-win-x64.zip`：完整便携运行目录，解压后启动主程序。
- `LyricConnector.exe`：主程序；单独运行时仍需要 ZIP 中的配置文件和资源目录。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 运行要求

- Windows 10 / 11 x64，.NET Framework 4.8 或更高版本。
- 可用的蓝牙 LE 适配器，以及已在 Windows 中配对的 iPhone。
- 程序未签名，尚未完成干净 Windows 环境安装验收。
