Lyric Connector 0.2.7 for Windows x64.

## 本次更新

- 改进 iPhone 蓝牙连接处理：连接过程中可以取消；读取 AMS 媒体服务最长等待 45 秒，并在失败时显示更具体的原因。
- 调整意外断连后的自动重连间隔为 15 秒，并在等待重连时保留连接错误提示，方便排查问题。

## 下载文件

- `LyricConnector-Setup-0.2.7-x64.exe`：单用户安装程序。
- `LyricConnector-0.2.7-win-x64.zip`：完整便携运行目录，解压后启动主程序。
- `LyricConnector.exe`：主程序；单独运行时仍需要 ZIP 中的配置文件和资源目录。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 运行要求

- Windows 10 / 11 x64，.NET Framework 4.8 或更高版本。
- 可用的蓝牙 LE 适配器，以及已在 Windows 中配对的 iPhone。
- 程序未签名，尚未完成干净 Windows 环境安装验收。
