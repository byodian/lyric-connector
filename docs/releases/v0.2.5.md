Lyric Connector 0.2.5 for Windows x64.

## 本次更新

- 重整桌面控制界面：紧凑控件、轻量列表、统一窗口边框，以及带真实蓝牙状态和进度的播放面板。
- 主窗口铺满可用宽度；宽窗口按 55% / 45% 分栏，窄窗口使用标签页。检索、设备操作及设置控件分别限制宽度。
- 新增内嵌歌词预览，复用悬浮窗的字体、颜色与渐进填色；歌词时间调整移到预览下方。
- 新增“简约 / 标准 / 大字体”快捷预设，分别对应 16px / 透明、24px / 45%、32px / 64% 背景不透明度。
- 不透明度支持输入 0–100、Enter / 失焦应用和滑块同步；字体整面点击展开，选择后立即生效。
- 歌词候选展示专辑信息，简化已应用状态，修复 150% 缩放时单选圆点偏移。
- 连接成功后收起设备操作；支持主动断开，并区分主动断开与意外掉线后的自动重连。
- 自动和手动歌词检索共用查询与排序路径，优先同步歌词，并保留用户已选版本。

## 下载文件

- `LyricConnector-Setup-0.2.5-x64.exe`：单用户安装程序。
- `LyricConnector-0.2.5-win-x64.zip`：完整便携运行目录，解压后启动主程序。
- `LyricConnector.exe`：主程序；单独运行时仍需要 ZIP 中的配置文件和资源目录。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 验证

- 原生 Windows 回归检查：111 项通过。
- 隔离界面交互与布局检查：97 项通过，包括多种窗口宽度、预设、百分比输入、字体选择和播放面板。
- 安装包通过 GitHub Actions 的原生 Windows runner 构建；WSL 中未运行生产构建。

- Windows 10 / 11 x64，.NET Framework 4.8 或更高版本。
- 可用的蓝牙 LE 适配器，以及已在 Windows 中配对的 iPhone。
