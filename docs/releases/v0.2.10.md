Lyric Connector 0.2.10 for Windows x64.

## Changes

- Recover iPhone media service discovery when Windows reports `Unreachable` by waiting for an active Bluetooth GATT session and retrying the AMS query.
- Refresh paired devices before manual and automatic connections, so reconnection can use a new device ID even if Windows also changes the iPhone's display name.
- Keep automatic reconnection running after repeated temporary failures while still showing the existing pairing repair guidance.

## Verification

- 112 logic checks and 125 native UI checks passed, including stale device IDs, renamed devices, repeated `Unreachable` responses, and the minimum startup width.
- A native Windows startup connected to the iPhone and loaded 45 lines of timed lyrics. A complete walk-away and return cycle still needs hardware validation.

## Downloads

- `LyricConnector-Setup-0.2.10-x64.exe`: per-user installer.
- `LyricConnector-0.2.10-win-x64.zip`: complete portable app directory.
- `LyricConnector.exe`: app executable; standalone use still requires the config file and assets from the ZIP.
- `SHA256SUMS.txt`: SHA-256 checksums for the release files.

## Requirements

- Windows 10 or 11 x64 with .NET Framework 4.8 or later.
- A Bluetooth LE adapter and an iPhone paired in Windows.
- The installer is unsigned and has not been validated on a clean Windows machine.
