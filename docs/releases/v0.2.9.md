Lyric Connector 0.2.9 for Windows x64.

## 本次更新

- 新增首次连接 Spotlight Tour：按配对、刷新并选择设备、发起连接三个步骤引导用户操作真实页面控件；连接成功后自动结束，跳过后不再自动显示。
- 简化设备连接区域，常驻显示设备列表和连接操作；将 Windows 蓝牙设置保留在连接帮助中，并隐藏引导期间重复的说明。
- 连续遇到蓝牙 `Unreachable` 或超时后，提示忽略旧配对并重新配对，同时暂停自动重连，等待用户手动重试。
- 将控制窗口默认宽度调整为最小宽度，并更新 README 中的主界面和首次连接引导截图。

## 下载文件

- `LyricConnector-Setup-0.2.9-x64.exe`：单用户安装程序。
- `LyricConnector-0.2.9-win-x64.zip`：完整便携运行目录，解压后启动主程序。
- `LyricConnector.exe`：主程序；单独运行时仍需要 ZIP 中的配置文件和资源目录。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 运行要求

- Windows 10 / 11 x64，.NET Framework 4.8 或更高版本。
- 可用的蓝牙 LE 适配器，以及已在 Windows 中配对的 iPhone。
- 程序未签名，尚未完成干净 Windows 环境安装验收。
